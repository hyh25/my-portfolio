监控数据流#

[Nginx 容器] ──暴露 /nginx_status 指标──→ [Nginx Exporter] ──采集──→ [Prometheus]
[宿主机系统] ──────────────── 采集 ──────→ [Node Exporter]  ──采集──→ [Prometheus]
                                                                          │
                                                                          ▼
                                                              [Prometheus 存储时序数据]
                                                                          │
                                                                          ├── [Grafana 查询展示] → 运维人员查看面板
                                                                          │
                                                                          └── [Alertmanager 规则判定] → 触发告警 → [邮件通知] → 运维人员

                          ▼
              运维人员查看实时日志

🏆 项目成果与关键指标#

可交付成果#

  • ✅ 个人作品集网站：内网可访问（http://192.168.0.200:8080），公网通过 GitHub Pages 可访问
  • ✅ 8 个 Docker 容器：稳定运行，全部配置 --restart=always（自动恢复）
  • ✅ 监控看板：Grafana 面板包含系统资源 + Nginx 状态，可视化展示
  • ✅ 告警闭环：5 条核心告警规则，邮件实时通知，已验证触发与恢复
  • ✅ 日志查询平台：Grafana 内实时检索 Nginx 访问日志（{job="nginx"}）

关键技术参数#

指标数值/说明
告警响应时间异常触发后 1~2 分钟发送邮件
日志查询响应1 分钟时间范围，秒级返回
备份保留策略每天 2:00 备份，保留最近 7 天
数据存储周期监控指标保留 15 天（Prometheus 默认）
服务恢复能力虚拟机重启后，所有容器自动启动

📌 项目亮点#

  1. 全链路自建：从操作系统安装到容器编排再到监控告警，独立完成。
  2. 故障驱动学习：踩遍了容器权限、网络通信、时间同步、速率限制等生产级坑点。
  3. 生产思维：采用 UID 对齐、host 网络、重定向兜底 等企业级解决方案。
  4. 文档完备：所有配置、命令、踩坑记录均已整理归档。
