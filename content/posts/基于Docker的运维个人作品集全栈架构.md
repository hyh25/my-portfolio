## 🔄 数据流向图（纯文本流程图）

### 监控数据流

```
[Nginx 容器] ──暴露 /nginx_status 指标──→ [Nginx Exporter] ──采集──→ [Prometheus]
[宿主机系统] ──────────────── 采集 ──────→ [Node Exporter]  ──采集──→ [Prometheus]
                                                                          │
                                                                          ▼
                                                              [Prometheus 存储时序数据]
                                                                          │
                                                                          ├── [Grafana 查询展示] → 运维人员查看面板
                                                                          │
                                                                          └── [Alertmanager 规则判定] → 触发告警 → [邮件通知] → 运维人员
```

### 日志数据流

```
[用户访问网站] ──→ [mysite 容器产生日志(stdout)]
                          │
                          ▼
              [改为“Systemd 日志重定向服务（docker logs -f）]
                          │
                          ▼
            [/var/log/mysite/access.log 宿主机文件]
                          │
                          ▼
              [Promtail 采集器 (读取文件新行)]
                          │
                          ▼ (HTTP Push)
              [Loki 存储引擎 (索引 + 存储)]
                          │
                          ▼ (Loki API 查询)
              [Grafana (Explore 日志查询)]
                          │
                          ▼
              运维人员查看实时日志
```

### 网站部署与备份流

```
[Hugo 源码 (本地)] ──hugo build──→ [public/ 静态文件]
        │                                    │
        ├── Git Push ──→ [GitHub Pages] ──→ 公网访问
        │
        └── SCP/容器部署 ──→ [mysite 容器] ──→ 内网访问

[网站文件] ── 每日凌晨2点 ──→ [tar 打包] ──→ [/root/backup/]
                                                │
                                                ▼
                                    保留最近7天，自动删除旧备份
```

## 🛠️ 技术栈清单

| 层级         | 技术组件       | 用途                   | 版本/备注               |
| :----------- | :------------- | :--------------------- | :---------------------- |
| **Web 服务** | Hugo           | 静态网站生成器         | Extended 版本           |
|              | Nginx          | Web 服务器 / 反向代理  | 官方 Alpine 镜像        |
|              | GitHub Pages   | 公网托管               | 免费 CDN 加速           |
| **容器化**   | Docker         | 应用容器化运行         | 所有服务容器化          |
|              | Docker Compose | 服务编排（可后续集成） | 待整合                  |
| **监控系统** | Prometheus     | 时序数据库 + 指标采集  | 端口 9090               |
|              | Node Exporter  | 宿主机系统指标         | 端口 9100               |
|              | Nginx Exporter | Nginx 状态指标         | 端口 9113               |
|              | Grafana        | 可视化面板             | 端口 3000               |
| **告警系统** | Alertmanager   | 告警分组/路由/通知     | 端口 9093               |
|              | SMTP (QQ邮箱)  | 邮件通知通道           | TLS 加密                |
| **日志系统** | Loki           | 日志存储索引引擎       | 端口 3100               |
|              | Promtail       | 日志采集器             | host 网络模式           |
|              | Docker Logs    | 日志重定向（兜底方案） | 后台 nohup 进程         |
| **自动化**   | Shell Script   | 自动备份脚本           | Cron 定时执行           |
|              | Crontab        | 定时任务调度           | 每天凌晨 2:00           |
| **网络**     | Bridge / Host  | Docker 网络模式        | 关键：host 解决通信问题 |

## 🏆 项目成果与关键指标

### 可交付成果

- ✅ **个人作品集网站**：内网可访问（`http://192.168.0.200:8080`），公网通过 GitHub Pages 可访问
- ✅ **8 个 Docker 容器**：稳定运行，全部配置 `--restart=always`（自动恢复）
- ✅ **监控看板**：Grafana 面板包含系统资源 + Nginx 状态，可视化展示
- ✅ **告警闭环**：5 条核心告警规则，邮件实时通知，已验证触发与恢复
- ✅ **日志查询平台**：Grafana 内实时检索 Nginx 访问日志（`{job="nginx"}`）

### 关键技术参数

| 指标         | 数值/说明                             |
| :----------- | :------------------------------------ |
| 告警响应时间 | 异常触发后 1~2 分钟发送邮件           |
| 日志查询响应 | 1 分钟时间范围，秒级返回              |
| 备份保留策略 | 每天 2:00 备份，保留最近 7 天         |
| 数据存储周期 | 监控指标保留 15 天（Prometheus 默认） |
| 服务恢复能力 | 虚拟机重启后，所有容器自动启动        |

## 📌 项目亮点

1. **全链路自建**：从操作系统安装到容器编排再到监控告警，独立完成。
2. **故障驱动学习**：踩遍了容器权限、网络通信、时间同步、速率限制等生产级坑点。
3. **生产思维**：采用 `UID 对齐`、`host 网络`、`重定向兜底` 等企业级解决方案。
4. **文档完备**：所有配置、命令、踩坑记录均已整理归档。
